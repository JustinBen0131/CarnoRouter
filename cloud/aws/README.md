# AWS cross-environment shard contract

This package is an optional execution surface for the provider-free Carno
stress benchmark. Forty-eight Lambda shards enumerate the sealed identity
universe so global blind indices remain stable, then construct and evaluate
only their SHA-256-assigned disjoint trace partition. A coordinator accepts a
run only when the union contains every one of the 28,800 local candidates
exactly once and every receipt SHA-256 matches the canonical local artifact.

The canonical full-evaluation digest is request-bound, not independently
recomputed inside each shard. Integrity comes from exact receipt reassembly
against the local campaign, so the cloud path cannot pass merely by echoing
that digest.

The lane does not call a model provider. AWS request IDs, billed duration,
memory, CloudWatch log bytes, and the final cost upper bound are runtime
receipts; they are never inserted into the byte-reproducible evaluator core.

The checked plan forbids IAM creation, networking changes, S3, retries beyond
one bounded retry, and retained compute. It requires an existing
least-privilege Lambda execution role, a valid SSO session, a governed exact
mutation route, and teardown readback. Those gates are not satisfied merely by
the presence of this code.
